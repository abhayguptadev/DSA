# Data Structures and Algorithms (DSA)

**A class-wise collection of Data Structures and Algorithms practice for university students.**

Welcome to my DSA repository! This project organizes my university DSA coursework, class-wise coding exercises, and class tests in one place. It serves as a learning record and revision resource as I strengthen my programming fundamentals and problem-solving skills.

Whether you're revising previous classes, reviewing coding exercises, or following along with your own DSA learning journey, this repository provides a simple place to explore the available practice material.

## Overview

The repository is organized around individual class sessions and class tests, making it easier to navigate the work completed during the university DSA program.

### What you'll find here

- **Class-wise practice:** Explore exercises organized by class or day.
- **Programming practice:** Review the code and examples available in each folder.
- **Class test materials:** Find the exercises and materials stored in `ClassTest`.
- **Revision support:** Revisit previously covered concepts and practice independently.
- **Learning progress:** Follow the repository as more coursework and solutions are added.

## Getting Started

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/abhayguptadev/DSA.git
```

### 2. Open the project directory

```bash
cd DSA
```

### 3. Explore the class folders

Open the repository in your preferred code editor, such as Visual Studio Code.

```bash
code .
```

If the `code` command is unavailable, open the folder manually in your editor.

### 4. Run the programs

Check the file extensions and instructions inside each folder. Use the appropriate compiler, interpreter, or development environment for the programming language used by that exercise.
